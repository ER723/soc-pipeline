# Contributing

This is a personal portfolio project documenting a working SOC escalation pipeline. It's not accepting external code contributions (the live implementation lives in a private companion repository), but feedback and questions are genuinely welcome.

- **Found an issue with the documentation or test methodology?** Open an issue describing it.
- **Questions about the architecture or how something was tested?** Open an issue — happy to explain.
- **Spotted something inaccurate?** Please flag it — accuracy is the whole point of this project.

No formal PR process, since there's no application code in this repo to contribute to.
